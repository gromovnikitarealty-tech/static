Политика обработки персональных данных

Актуальная версия · 2026

1. Общие положения

1.1. Настоящая политика составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных».

1.2. Оператором обработки данных является Администрация информационного ресурса nevaart-lsr.ru (далее — Оператор).

1.3. Политика применяется ко всей информации, которую Оператор может получить о посетителях веб-сайта https://nevaart-lsr.ru.

1.4. Обработка данных осуществляется без трансграничной передачи и без внесения в структурированные базы данных. Данные уничтожаются сразу после завершения сеанса связи.

1.5. Для оперативной обработки запроса, проверки доступности лотов и фиксации бронирования номер телефона Пользователя может быть передан в уполномоченную информационную систему партнёрского бронирования для последующей маршрутизации в Департамент по работе с клиентами компании-девелопера. Отправка формы является согласием Пользователя на такую передачу в целях получения обратной связи по объекту.

1.6. Связь с Администрацией: info@nevaart-lsr.ru

2. Основные понятия

2.1. Оператор — Администрация информационного ресурса, самостоятельно или совместно с уполномоченными партнёрами осуществляющая обработку персональных данных.

2.2. Персональные данные — любая информация, относящаяся к определённому Пользователю сайта.

2.3. Пользователь — любой посетитель веб-сайта https://nevaart-lsr.ru.

2.4. Обработка — сбор, использование, передача уполномоченному партнёру, уничтожение персональных данных.

3. Цели обработки

Цель: обратная связь с Пользователем по оставленному запросу об объекте недвижимости.

Данные: номера телефонов.

Правовое основание: Федеральный закон № 152-ФЗ «О персональных данных».

Виды обработки: сбор, использование, передача, уничтожение.

4. Права пользователя

4.1. Пользователь вправе запросить информацию об обработке своих данных, потребовать их уничтожения или отозвать согласие, направив запрос на info@nevaart-lsr.ru с пометкой «Отзыв согласия».

5. Хранение и передача данных

5.1. Персональные данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством и пунктом 1.5 настоящей Политики.

5.2. Срок обработки — до достижения цели, после чего данные уничтожаются.

6. Конфиденциальность

Оператор обязуется не раскрывать и не распространять персональные данные без согласия субъекта, если иное не предусмотрено федеральным законом.

7. Заключительные положения

По вопросам обработки персональных данных: info@nevaart-lsr.ru

Актуальная версия Политики расположена в открытом доступе по адресу: nevaart-lsr.ru/politika/
